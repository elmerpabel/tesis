# Taxonomía de Bloom y Plantillas Estandarizadas de Tesis

## 1. Verbos de Acción según la Taxonomía de Bloom (Objetivos Generales y Específicos)

> **Regla metodológica:** El **objetivo general** debe pertenecer a un nivel cognitivo **igual o superior** al de los objetivos específicos. Nunca usar verbos vagos o no medibles como *"conocer"*, *"saber"*, *"entender"* o *"ver"*.

| Nivel Cognitivo | Uso recomendado en Tesis | Verbos de Acción Precisos |
| :--- | :--- | :--- |
| **1. Recordar / Identificar** | Diagnóstico inicial, inventario, línea base | Identificar, describir, enumerar, registrar, caracterizar, definir, relevar |
| **2. Comprender** | Revisión teórica, clasificación de factores | Clasificar, explicar, interpretar, resumir, categorizar, distinguir, sistematizar |
| **3. Aplicar** | Implementación técnica, simulación, ejecución de protocolos | Aplicar, implementar, ejecutar, calcular, modelar, operar, utilizar, adaptar |
| **4. Analizar** | Estudios correlacionales, comparativos, causales, diagnóstico profundo | Analizar, comparar, contrastar, correlacionar, determinar, examinar, diferenciar, descomponer |
| **5. Evaluar** | Validación de impacto, auditoría, evaluación técnico-económica | Evaluar, validar, comprobar, verificar, estimar, valorar, juzgar, medir |
| **6. Crear / Proponer** | Tesis propositivas, ingeniería de diseño, modelos nuevos | Diseñar, proponer, formular, desarrollar, construir, optimizar, elaborar, estructurar |

## 3. Plantilla: Adaptación Rápida por Profesión / Área de Conocimiento

| Área / Profesión | Norma habitual | Diseños frecuentes | Instrumentos habituales |
| :--- | :--- | :--- | :--- |
| **Ingeniería (Metalúrgica, Industrial, Civil, Sistemas, Minas, Mecánica)** | APA 7 / IEEE / ISO 690 | Experimental, pre-experimental, optimización, propuesta técnico-económica, simulación | Pruebas de laboratorio, sensores, KPIs operativos, simuladores, matrices de ingeniería, evaluación VAN/TIR |
| **Ciencias de la Salud (Medicina, Enfermería, Odontología, Farmacia)** | Vancouver / APA 7 | Observacional analítico (casos-controles, cohortes), transversal, ensayo clínico | Historias clínicas, biomarcadores, escalas clínicas validadas, fichas epidemiológicas |
| **Administración, Economía, Contabilidad y Marketing** | APA 7 | Correlacional, descriptivo-propositivo, estudio de caso, econométrico | Encuestas Likert, estados financieros, series de tiempo, indicadores BSC/KPI |
| **Educación y Psicología** | APA 7 | Cuasi-experimental, correlacional, fenomenológico, investigación-acción | Tests psicométricos validados, rúbricas, pretest/postest, entrevistas semiestructuradas |
| **Derecho y Ciencias Políticas** | APA 7 / Chicago / ISO 690 | Dogmático-jurídico, socio-jurídico, análisis comparado, estudio de expedientes | Fichas de análisis jurisprudencial, matrices normativas, entrevistas a especialistas |
| **Arquitectura y Diseño** | APA 7 / ISO 690 | Proyectual, descriptivo-propositivo, análisis espacial/urbano | Fichas urbanas, levantamientos planimétricos, encuestas de percepción espacial, simulación energética |

## 4. Plantilla: Cronograma Semanal (Fase 6)

| Semana(s) | Etapa / Actividad | Entregable Concreto | Hito de Control |
| :--- | :--- | :--- | :--- |
| Sem. 1–2 | Diagnóstico, título y Matriz de Consistencia | Ficha base + Matrices aprobadas | Revisión 1 con asesor |
| Sem. 3–5 | Revisión bibliográfica y Marco Teórico | Antecedentes + Bases teóricas | Verificación de citas/DOIs |
| Sem. 6–7 | Diseño metodológico y validación de instrumentos | Instrumento validado por expertos | Constancia de validación |
| Sem. 8–10 | Trabajo de campo / laboratorio / recolección | Base de datos limpia | Control de calidad de datos |
| Sem. 11–12 | Procesamiento estadístico / análisis y discusión | Capítulos de Resultados y Discusión | Revisión 2 con asesor |
| Sem. 13–14 | Conclusiones, recomendaciones y redacción final | Borrador completo unificado | Control Turnitin (< umbral) |
| Sem. 15–16 | Levantamiento de observaciones y diapositivas (6x6) | Tesis final + PPTX de sustentación | Ensayo y sustentación ante jurado |
